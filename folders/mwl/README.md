# Folders do MWL.camera

Os PDFs desta pasta são cópias dos que o mwl.seg.br oferece para baixar:

- `MWL-camera-folder.pdf`: folder para o cliente
- `MWL-ODL-integrador.pdf`: folder para integradores

A fonte editável fica no repositório **mwlsegbr**, em `materiais/fonte/` (`folder.html`, `integrador.html` e `gerar.mjs`). Para mudar um folder, edite lá, gere o PDF de novo e copie o resultado para cá.
