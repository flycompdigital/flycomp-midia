# LuminaT21: identidade visual

Recriação do kit de logos (referência em `originais/kit-de-logos-referencia.jpg`) para uso em site, documentos e redes sociais.

## Logos (`logos/`)

| Arquivo | Uso |
|---|---|
| `luminat21-logo-horizontal.png` | Principal, fundo transparente, para fundos claros |
| `luminat21-logo-horizontal-assinatura.png` | Com a frase "A Luz do Amor ♥ A Força da Inclusão" (documentos, capas) |
| `luminat21-logo-empilhado.png` | Versão vertical (Lumina / T21) |
| `luminat21-logo-fundo-escuro-transparente.png` | Versão com brilho, transparente, para fundos escuros |
| `luminat21-logo-escuro.png` | Versão pronta sobre fundo preto (apresentações, telas) |
| `luminat21-icone-1024.png` | Quadrado 1024 px (avatar, ícone) |

O banner ilustrado das famílias está em `originais/banner-familias.jpg`.

## Tipografia

- Marca: **Courgette** (Google Fonts, licença OFL), em `fonte/`.
- Textos: Geist ou Inter.

## Regenerar

O script `gerador/logo.py` cria os HTML e o `gerador/shot.py` renderiza os PNG com Playwright. Ajuste os caminhos se for rodar em outra pasta.
